# Orca 全量中文支持需求

## 背景

Orca 当前没有成熟的国际化体系。已有中文支持只覆盖少量 HelloAGENTS / 飞书设置入口，且以 `zh?.xxx ?? English` 的临时方式散落在组件中。目标是让桌面端界面能够自然切换到简体中文，同时保证英文默认体验、功能逻辑和自动化测试不受影响。

## 范围

- 建立正式 renderer i18n 基础设施，支持 `system`、`en`、`zh-CN`。
- 保留现有 `GlobalSettings.appLanguage` 设置，并让语言选择即时影响界面。
- 提供英文和简体中文翻译表，确保 key 结构一致、回退稳定、插值可测试。
- 分阶段迁移用户可见文案，优先覆盖设置、Agent 编排、飞书配置、导航、工作区、任务、终端、Source Control、对话框、toast、空状态和错误提示。
- 调整测试断言，避免关键测试被硬编码英文文案绑死。
- 增加中文翻译术语表、开发规范和基础自动化测试。

## 非范围

- 不翻译代码标识符、协议字段、命令名、配置键、日志结构字段。
- 不把用户输入、仓库内容、终端输出、Agent 原始输出强制翻译。
- 不改变 Feishu / HelloAGENTS / Git 工作流的业务逻辑。
- 不引入重型 i18n 依赖，除非后续发现现有轻量实现无法承载复数、日期、数字等需求。

## 成功标准

- `pnpm run typecheck:web`、相关 i18n 单元测试、lint 通过。
- 英文和中文翻译 key 完全一致，缺 key 会测试失败。
- `system` 能根据浏览器 / 桌面语言解析到合适 locale。
- 现有设置页中的语言选择、Agent 编排、飞书配置中文文案自然、语义准确。
- 新增文档说明中文术语、翻译边界和测试要求。
